# 5 Açılır/Kapanır Menü Tasarımı (Interactive Menu Showcase)

Modern web arayüzlerinde en sık kullanılan 5 farklı mobil menü ve açılır/kapanır (toggle) etkileşim desenini tek bir sayfada toplayan, şık ve interaktif bir frontend showcase projesi.

## Özellikler

* **5 Farklı Animasyon Deseni:** Tam ekran overlay, sağdan kayan off-canvas drawer, içeriği iten push navigasyon, yukarıdan açılan accordion dropdown ve alttan açılan modern bottom-sheet.
* **Modern Tasarım Dili:** `Space Grotesk` ve `JetBrains Mono` fontları, koyu tema uyumu, yumuşak geçişler (cubic-bezier) ve her menüye özel renk paletleri.
* **Saf Teknolojiler:** Harici kütüphane veya framework gerektirmeyen, tamamen vanilla HTML, CSS ve JavaScript ile yazılmış hafif yapı.

## Proje Yapısı

* index.html -> 5 farklı açılır menü mekanizmasını, stillerini ve JavaScript etkileşim kodlarını içeren tek parça kaynak dosya.

## Kullanım

1. Projeyi bilgisayarınıza klonlayın veya indirin.
2. index.html dosyasını herhangi bir web tarayıcısında açın.
3. Sayfadaki hamburger ikonlarına tıklayarak farklı menü açılış animasyonlarını deneyimleyin.

## Lisans
Bu proje tamamen açık kaynaklıdır ve dilediğiniz gibi geliştirip projelerinizde kullanabilirsiniz.
